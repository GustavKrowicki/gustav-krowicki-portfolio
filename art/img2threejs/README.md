# img2threejs sources for city buildings

Procedural Three.js buildings for the city, built with the img2threejs skill instead of Krea 3D generation.
The generated factories live in `lib/city/models/`; these folders hold everything needed to regenerate them.
Projection, scale and sprite-export rules: `docs/city-rules.md`.

## Setup

The img2threejs skill v2.0.0 (the current release), installed with its CLI:
`npx --yes img2threejs@latest install --host claude`, check with `npx --yes img2threejs@latest doctor`.
Buildings use the base skill with the `generic` profile; no plugins are needed. Plugins come from the separate
`img2` harness (`npx --yes @img2threejs/img2@latest install --yes`, then `img2 add <id>`); the private
`environment` plugin is planned for ground and surroundings.

## New building

`tools/new_building.sh <folder> "<Name>" <factoryFile> <footprintW> <footprintH>` copies `_template/`
(`building.env`, `rebuild_spec.sh`, `pass.sh`, `sync_factory.sh`). Then:

1. Put the reference image in `<folder>/ref/` (ignored by git, see `.gitignore`) and set `REF` in `building.env`.
2. Write `assessment.json` with the skill's `stage2_spec/new_pre_spec_assessment.py`, and author `build_spec.py`
   in wu (1 wu = 1 model unit, `docs/city-rules.md` section 4), with the entrance from section 6.
3. `rebuild_spec.sh`, then `pass.sh gen <pass>` and `pass.sh gates <pass>` per pass. The template's gates
   compare against the reference image, since a new building has no live sprite to match.
4. Register the factory in the entrance lab's `MODELS` and export sprites with `converterSettings()` from
   `lib/city/units.ts`.

## Pipeline (per building)

1. **Style source:** a "game-like" image made in Google AI Studio from a real photo (kept outside the repo).
2. **Structure** (when an old Krea model exists): measure it, never copy its geometry.
   - `tools/glb_topdown.py <glb> <out> 512` rasterises a top-down height and colour map.
   - `tools/aligned.py`, `tools/vectorize.py`, `tools/ground_trees.py` turn those maps into building outlines with
     roof heights, ground regions and tree positions (`measure/*.json`).
   - `tools/match_converter.py <glb> <spriteDir> <prefix>` recovers the converter zoom / vertical offset an old
     sprite set was exported with.
3. **Spec:** `build_spec.py` writes the ObjectSculptSpec (components, facade systems from `facades.py`, flat
   evidence-backed materials, calibration from `measure/*.json`). `rebuild_spec.sh` re-runs it and strict-validates.
4. **Factory:** `pass.sh gen <pass-id>` generates `src/createObjectModel.ts`; `sync_factory.sh` copies it into
   `lib/city/models/`.
5. **Review and sprites:** `/tools/sprite-converter/entrance-lab?model=<id>` renders the model. Its `sprite` view
   is the sprite converter's exact maths (verified pixel-identical on the old LEGO HQ GLB) plus `pitch`, `zoom`,
   `voff` and `focusNode` options. `window.__shoot(name, options)` posts captures to `tools/sheet_receiver.py`
   (port 8765); `tools/static_cors.py <dir> 8766` serves an old GLB for the lab's `krea` model.
   `tools/sprite_compare.py`, `tools/calibrate.py` and `tools/grid_test.py` compare against the live sprites,
   calibrate colours and place variants on the 2:1 city grid; `tools/city_shot.mjs` screenshots the running city.

## Not in the repo

- Reference images (`ref/`): AI Studio images and photo crops. LEGO HQ: `Generated Image January 27, 2026 -
  9_04PM.jpeg` (AI Studio) and the aerial `LEGO-Campus-C-F-Moeller--img-82007-w2500-h1611-x2.jpg`.
- The old Krea model: `LEGO HQ.glb`.
- `object-sculpt-spec.json` (regenerated by `rebuild_spec.sh`), `src/`, renders and previews.
